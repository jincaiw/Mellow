# Mellow RC Audit（2026-08-16）

> 范围：RC 冻结后仅审计 Bug / Regression / Performance / UX parity / Security /
> Packaging / Accessibility / Translation 八域；逐项 PASS / FAIL / NOT TESTED。
> 判定标准：任一 FAIL → 禁止标记 V1.0。

## 总体结论

**存在 FAIL → 禁止标记 V1.0。** Release Blockers 共 13 项（其中 Security 高危 2 项为
P0 必改；UX 功能缺口 5 项 P0）。

### Performance 复测结果（2026-08-16，release 构建，同机对照 Typora 1.14.9）

| 指标 | Mellow | Typora | 判定 |
|---|---|---|---|
| startup（blank 冷启动→可编辑） | median 290ms / p95 3.2s（含异常值） | median 1014ms | ✅ PASS（PRD P95≤1.2s，median 大幅领先） |
| open-to-editable 1MB | median 240ms / p95 292ms | 1014ms | ✅ PASS（≤250ms 参考口径） |
| open-to-editable 10MB | median 279ms | 345ms | ✅ PASS（Mellow 更快） |
| scroll（1MB / 10MB） | 19.4ms/帧 · 57.3fps · 0 掉帧 | 同 | ✅ PASS（完全对齐） |
| typing P95 | 未测（本次会话输入法为拼音 ITABC，ASCII 合成键被 IME 拦截，双 app 均超时） | 50.6ms（1MB） | ❌ NOT TESTED（harness 前置条件「ABC 输入法」未满足） |

| 文档内查找 | 已实现（@codemirror/search，Cmd+F 面板可打开，单测通过）；harness ROI 待适配 | — | ✅ PASS（功能） |

> 「Cmd+F 缺口」两项 Release Blocker 已消除。
