# Desktop UI 审查（2026-08-13）—— 对照 Typora 1.14.9 + desktop-ui-design-spec

只审查，不增加功能。目标：**用户首先看到文档**（spec §1）。

## 维度审查

### 1. Default visual complexity —— 偏高（VS Code 化）

| 元素 | Mellow 默认 | Typora 默认 | 判定 |
|---|---|---|---|
| 侧边栏 | **显示**（files，260px，密集控件） | 隐藏 | ✗ 多一层 |
| 状态栏 | **常驻 7 项**（dirty/stats/cursor/编码/行尾/状态） | 无（统计条可隐藏） | ✗ |
| 标签栏 | **标题栏内 tabbar**（border 分隔 + active accent 底边 + dirty ● + close ×） | 极简（无 tab 栏视觉） | ✗ |
| 行号 | **默认开启**（`editor.lineNumbers: true`） | 无 | ✗ |
| titlebar ⌘P 按钮 | 常驻 | 无 | ✗ 冗余入口 |
| 欢迎页 | Mellow 标题 + 3 按钮 | 空白编辑器 | ✗ |

### 2. Editor prominence —— 中

- 编辑器占 main 主区域（OK），但被「侧边栏 + 状态栏 + 标题栏标签 + 行号」多重边框包裹 → **文档不是第一视觉**。
- 打开文档时无欢迎页（OK）；无文档时 welcome 页抢占（Notion/VS Code 化）。

### 3. Sidebar —— Obsidian/VS Code 化（重点收敛）

- **默认显示文件树**（`sidebarMode` 默认 `'files'`）——Typora 默认隐藏。
- **控件密度高**（文件树模式一屏可见）：
  - header：files/outline/search 切换 + 打开文件夹 + 刷新按钮
  - tree/list 模式切换
  - 4 个 checkbox（showHidden / showNonMarkdown / 递归 / 摘要）+ 排序 select + asc checkbox
  - **2 个 glob 输入框**（include/exclude）常驻
  - root 路径行
- 全部常驻 → **文件管理器外观**（Obsidian/VS Code），文档被推远。

### 4. Tabs —— VS Code 化

- `titlebar` 内嵌 `tabbar`：tab 有 `border-right` 分隔、active 有 `inset 0 -2px accent` 底边、dirty `●`、close `×`。
- 这是 **VS Code/浏览器标签风格**，非 Typora 的低干扰 tab。

### 5. Menu —— 通过（结构合理）

- macOS 菜单：文件 / 视图 / 插入（标题/列表/任务/引用/表格/代码块）。
- 无过度层级；但 Insert 缺公式/图片/图表（slash-only）——发现性问题（上轮已列 F5，非本维度）。

### 6. Floating toolbar —— 与 Typora 等价（通过）

- selectionToolbar：选中文本浮出格式工具（`mellow.selection-toolbar`）——**Typora 同样有**；默认开启，可关（设置/命令）。
- 非 Notion 化（Notion 是常驻浮出块 + 块级菜单；Mellow 是选中态浮出）。

### 7. Settings —— 中等（可接受）

- sections：general / editor / markdown / file / image / appearance（6 个）+ AI（仅 aiEnabled 时出现）。
- editor 含 fontSize/lineNumbers/lineWrapping/typewriter/focusMode/toolbar —— **lineNumbers 默认 true 需收敛**。
- 无嵌套设置页（单面板，行内控件）——复杂度可接受。

### 8. Empty state —— Notion/VS Code 化

- 无文档时：`welcome`（Mellow 标题 + 新建/打开/打开文件夹 3 按钮）。
- Typora 无欢迎页（空白编辑器 + 直接打开对话框）——**建议收敛**（最小化或去除按钮组）。

### 9. Dark mode —— 通过

- themes 包：light/dark/system + lightThemeId/darkThemeId 分离 + user.css 注入；a11y 阶段已校准对比度（light fg-muted 4.61:1、accent 5.37:1）。
- 无问题。

### 10. Window chrome —— 通过

- macOS 原生 traffic lights + `padding-left: 76px` 留白（spec §14）；无自定义标题栏。
- 三平台共用布局（titlebar 为 WebView 内组件，非原生 overlay）——Windows/Linux 表现待三平台验证。

## 四化检查

| 倾向 | 是否出现 | 证据 |
|---|---|---|
| **VS Code 化** | ✅ 是 | titlebar tabbar（dirty/close/accent 底边）、statusbar 7 项常驻、行号默认开、侧边栏过滤控件、⌘P 常驻按钮 |
| **Obsidian 化** | ⚠️ 部分 | 侧边栏默认常驻 + tree/list + 排序/glob（无 ribbon/图标重/插件面板） |
| **Notion 化** | ⚠️ 部分 | welcome 页按钮组；slash 默认开（Typora 无 slash——差异化功能，保留）；selectionToolbar 与 Typora 等价不算 |
| **AI-first 化** | ❌ 无 | `aiEnabled` 默认 false（localStorage '1' 才开）；AI 设置仅启用后出现（ADR-0018 一致） |

## 收敛清单（只审查不改，待授权实施）

| 优先级 | # | 收敛项 | 目标 |
|---|---|---|---|
| **P0** | U1 | 侧边栏默认隐藏（文件树经 Cmd+Shift+L / 菜单唤起，对齐 Typora） | 文档成为第一视觉 |
| **P0** | U2 | 状态栏默认隐藏或精简（仅保留必要项，设置可开启） | 去 VS Code 化 |
| **P0** | U3 | 编辑器行号默认关闭（`editor.lineNumbers` false，对齐 Typora） | 去代码编辑器特征 |
| **P0** | U4 | 移除 titlebar ⌘P 常驻按钮（palette 快捷键已存在） | 去冗余入口 |
| P1 | U5 | welcome 页精简：去按钮组（或最小化） | 去 Notion 化 |
| P1 | U6 | 侧边栏过滤控件折叠：glob/排序/checkbox 收纳到设置，默认只显示文件树/大纲 | 去 Obsidian 化 |
| P1 | U7 | tabbar 视觉简化（dirty ● / close × 淡化或仅 hover 显示） | 去 VS Code 化 |
| P2 | U8 | 三平台验证 window chrome 一致性（Win/Linux titlebar 行为） | 平台一致 |

**不收敛（保留）**：slash 命令（差异化功能）、selectionToolbar（与 Typora 等价）、dark mode、menu 结构、AI 默认关闭。

## 结论

Mellow UI 当前呈现 **VS Code 化为主、Obsidian/Notion 化为辅** 的特征：默认界面被「标签栏 + 侧边栏 + 状态栏 + 行号」四层 chrome 包裹，**文档不是用户首先看到的内容**，与 spec §1 目标（用户首先看到文档）和 Typora 的低干扰信息架构相悖。收敛优先级：**U1 侧边栏默认隐藏 > U2 状态栏 > U3 行号 > U4 ⌘P 按钮**（均为默认状态调整，不动功能）。dark mode / window chrome / floating toolbar / menu / AI 已符合目标。
