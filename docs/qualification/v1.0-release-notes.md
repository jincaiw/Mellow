# Mellow V1.0 Release Notes

- 版本：**1.0.0**
- 日期：2026-08-16
- 构建：macOS arm64（Apple Silicon）

> Mellow 是一款 Typora 级跨平台 Markdown 编辑器：单一编辑表面、实时预览、中文输入法
> 优先、数据安全优先。

## 核心能力

- **Live Markdown 引擎**：marker reveal（标题/粗体/斜体/删除线/行内代码）、表格、数学
  （KaTeX）、Mermaid、Footnote、YAML front matter、GitHub Alerts、TOC、图片工作流
  （粘贴/拖拽/复制到 asset 目录/移动/重命名/回收站）。
- **中文输入法**：IME Composition Guard（合成期间渲染冻结、结束恢复），简体拼音矩阵
  8/8 无 corruption，合成后 Undo 不破坏文本与 marker。
- **文件安全（File Safety 5/5）**：原子保存（temp→flush→fsync→rename→verify）、
  外部修改冲突拒绝覆盖、崩溃恢复、symlink 保存保真、权限保留；data loss = 0、
  silent overwrite = 0、Source Fidelity（Open→Save 字节级 0 diff，135 文件）。
- **安全 Auto Update**：签名更新（内嵌公钥校验）、下载后校验（篡改拒绝）、release
  channel（stable/beta）、更新前备份 + 启动健康确认 + 失败回滚；更新只发送版本/平台
  元数据，**不自动上传任何用户数据**。
- **安全加固**：Reader HTML DOM 白名单净化（实体编码绕过已封堵）、链接点击系统浏览器
  打开 + webview 导航限制、CSP、远程图片默认不加载（设置可开启）、无遥测/AI/上传。
- **导出**：打印（Cmd+P）、导出 PDF（CJK 全支持，Noto Sans SC 嵌入）、导出 HTML
  （with-theme 单文件 + 白名单 sanitize）。
- **编辑体验**：命令面板、Slash 命令、Quick Open、文档内查找（Cmd+F）、代码围栏语言
  补全、Pin Folder、状态栏/侧边栏可隐藏、Focus/Typewriter 模式、10MB 大文件模式。
- **国际化**：简体中文 / English（zh-CN 与 en-US 100% 对齐）。
- **无障碍**：focus ring、≥3:1 对比度、reduced-motion、语义标签、键盘导航。

## 已知限制

- 自动更新 endpoints 为占位地址（`updates.mellow.app`），上线前替换为真实更新服务器。
- 远程图片默认不加载（隐私默认），可在设置开启。
- 仅 macOS 完成真机验证；Windows/Linux 与签名公证需对应基础设施后回填。
