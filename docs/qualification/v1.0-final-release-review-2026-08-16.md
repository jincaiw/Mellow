## Blockers（存在 FAIL → 不发布）

### A. 代码级 FAIL（本仓库可修）

1. **Security M1 — CSP 缺失**（`csp: null`）
   - 修复计划：配置合理 CSP（`script-src 'self'`、`img-src` 白名单等）；先验证前端无内联脚本/eval 后收紧；回归安全审计。
2. **Security M2 — 远程图片打开即隐式加载**（默认联网冲突）
   - 修复计划：新增「加载远程图片」设置，默认 Off；`img.src` 改为占位 + 点击确认加载（对齐 Typora）。
3. **UX 收敛 U1-U4（P0）**：侧边栏默认隐藏 / 状态栏默认隐藏 / 行号默认关 / 移除 titlebar ⌘P 按钮。
   - 修复计划：默认值翻转 + 条件渲染（工作量 S，已具备 settings 基础）。
4. **Typora UX Score 未正式计分（≥92 无据）**
   - 修复计划：按 PRD §131 计分表运行正式 UX Score；补齐 ~35 项 NOT TESTED parity 项（Win/Linux 行为）。

### B. 基础设施依赖 NOT TESTED

5. Windows：构建 + IME 矩阵 + 安装矩阵 → 需 Windows runner/真机（`release.yml` 已就绪）。
6. Linux：构建 + fcitx5/ibus + 安装矩阵 → 需 Linux runner/真机。
7. macOS Signed + Notarized → 需 Developer ID 证书 + notarytool 凭据（CI secrets）。
8. typing P95 复测 → 需 ABC 输入法环境（当前机器为拼音 ITABC，合成键被 IME 拦截）。
9. Caret/IME/Undo 15/15 跨平台 → 依赖 Windows/Linux IME 矩阵回填。

## 修复顺序建议

1. Security M1（CSP）+ M2（远程图片默认关闭）—— Release Blocker（安全）。
2. UX 收敛 U1-U4 + 正式 UX Score 计分。
3. 基础设施：Windows/Linux runner + Apple 凭据 → 触发三平台 CI → 回填三平台/IME/typing/安装矩阵。
4. 全部 18 项复验通过后，方可生成 V1.0 Release Notes。
