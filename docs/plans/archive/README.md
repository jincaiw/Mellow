## 为什么归档

V4 于 2026-09-01 取代 V3，V5 / V6 / B1 又各自以「轮次」形式追加，导致：

1. **施工依据二义** —— 同一个对标项在不同文档里有不同结论（例：Tabbar 去留、`.editor-topbar` 去留）；
2. **状态看板冲突** —— 各文档记录的代码基线与缺陷清单停留在不同时间点；
3. **回归风险** —— 新接手者可能照旧文档实施已被关闭或已被推翻的条目。

V7.0 以 **2026-09-11 @ `079cd5d`（v1.5.5）** 为唯一代码基线，以 Typora 官方文档 + 1.14.9 真机 dump 为唯一参考模型，重新做了全量对照，并把历史决策收敛为 §12 的 D-A ~ D-K 待裁决表。
